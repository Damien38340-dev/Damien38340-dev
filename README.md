## 💼 What I built professionally

### Quoting application interfaced with the Sylob ERP
*Depagne, industrial SME (Isère, France) - sole developer, 16 months - proprietary, no public repository*

Used daily by ~20 people in the sales department, around 100 quotes a day on electrical-network equipment.

**End to end, on my own:**

- Requirements gathering with the sales team, data modelling (MCD/MLD), UI mockups, user stories
- Back end in Java / Spring Boot, REST API, hexagonal architecture, MariaDB
- Front end in Vue.js / TypeScript
- **ERP synchronisation over REST**: referential consistency, full and incremental reconciliation, error handling and recovery
- **Server setup from scratch**: Linux, Docker, MariaDB, nginx as a reverse proxy in front of the containerised back end
- **CI/CD** with Gitea Actions, gated by unit and integration tests
- **Corrective and evolutionary maintenance**: shipping fixes and new features month after month without breaking what was already live
- Technical and user documentation published as a wiki

What demanded the most discipline was evolving the application without degrading it. Hence the hexagonal architecture and the automated test coverage.
